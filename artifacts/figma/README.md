# Keen editable design import

`keen-desktop-ui-replica.svg` contains two 1440 × 920 editable vector frames:

- Home — centered learning request workbench and learning queue.
- Learning Feed — task rail and month calendar.

The SVG uses Keen's current code tokens and deterministic Browser Demo copy. It does not add provider success, calendar writes, document ingestion, citations, or generated learning results.

Import into Figma with **File → Place image…** or drag the SVG onto the canvas. Figma will preserve the vector groups, text, fills, strokes, and layer IDs. Repeated structures are grouped but are not Figma component instances until converted inside Figma.
